# Build inputs and provenance

This page separates what was **measured** from what is only a source association. The v0.1.0 boot files are preserved test artifacts; this repository does not claim a clean, bit-for-bit reproducible build.

Licensing: the Linux kernel and its patch remain under their upstream licenses, primarily [GPL-2.0](../LICENSES/GPL-2.0.txt); the loader remains under [GPL-3.0](../LICENSES/GPL-3.0.txt). Tails and its included packages have their own licenses. The root MIT license covers only this repository's original documentation and glue, not those third-party works.

The Linux source baseline is [stable v7.1.7](https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tag/?h=v7.1.7). The public PS5 patch candidate used for source comparison is [ps5-linux-patches commit `56922cf`](https://github.com/ps5-linux/ps5-linux-patches/tree/56922cf9af91142cdcf7d54cbcfb3d46bdfb397a). Its exact [patch](https://github.com/ps5-linux/ps5-linux-patches/blob/56922cf9af91142cdcf7d54cbcfb3d46bdfb397a/linux.patch) is mirrored in this repo as `source/kernel/linux.patch`; the final kernel `.config` is mirrored as `source/kernel/final.config`. The original source tree's exact correspondence to that public patch was **not independently proved**. The local build used GCC 14 and enabled `NETFILTER_XTABLES_LEGACY`, `IP_NF_IPTABLES_LEGACY`, `IP6_NF_IPTABLES_LEGACY`, `IP_NF_FILTER`, `IP_NF_NAT`, `IP_NF_MANGLE`, `IP6_NF_FILTER`, `NETFILTER_XT_TARGET_HL`, and `IP_NF_TARGET_TTL`, then ran `olddefconfig` and built `bzImage modules`.

For Tails itself, use the [official Tails 7.17 USB image and verification page](https://tails.net/install/download/) rather than a reposted image. This repository does not contain the Tails live filesystem. The release initrd contains unmodified Tails components and modified PS5 startup hooks, which can be inspected in `source/initramfs`. The development diagnostic in that exact initrd checks for `ps5_graphics_diagnostic=1` and the **test USB's** FAT ID `618F-B6CA` before writing a report. Other USB IDs will not satisfy that collector. It is **off** in the example command line, and is not needed for ordinary startup. Unlike an official Tails image, this experimental initrd has not had a general privacy audit.

The exact physical test command line used `BOOT_IMAGE=/bzImage`, `initrd=/initrd.img`, Tails' live-boot and hardening options, `FSUUID=618F-B6CA`, `amdgpu.force_1080p=1`, and the optional diagnostic flag. The public [cmdline.example.txt](../cmdline.example.txt) replaces the one USB ID with a placeholder and omits the diagnostic flag. That **specific public sample** has not itself been physically retested, although the diagnostic service is explicitly conditional on the flag.

Original full reports, personal hardware identifiers, photos, and device-specific staging scripts are intentionally omitted from the public repo. The measurements above were taken from saved local project records dated 2026-11-14. See [Security](SECURITY.md) for the scope and limits of those measurements.
